# طلب توضيح إذن استخدام RSS وصفحات المشاريع

هذه مسودة فقط، لم تُرسل إلى أي طرف.

إلى دعم مستقل / حسوب،

أنا david atef، مطور مشروع راصد RASED: https://github.com/deved234/rased

أطوّر تطبيق Windows محليًا ومفتوح المصدر لمتابعة خلاصة https://mostaql.com/rss وتنبيه المستخدم للمشاريع الجديدة، دون خادم وسيط أو الدخول لحسابه أو إرسال عروض آلية. قبل توسيع توزيع التطبيق، أرجو تأكيد السماح وحدود الاستخدام المطلوبة كتابةً.

التنفيذ الحالي يفحص RSS افتراضيًا كل 5 ثوانٍ، مع خيارات 2 و15 ثانية، ويطبق التهدئة عند الرفض والأخطاء وRetry-After. قد يجلب صفحة المشروع العامة لاستخراج التصنيف والميزانية والمهارات والوصف، بطلب HTML واحد في الوقت نفسه وبفجوة ثانيتين على الأقل بين بدايات الطلبات، مع تخزين محلي للعرض. كل نسخة تتصل من جهاز صاحبها؛ قد توجد نسخ متعددة.

هل تسمحون بهذه الطريقة؟ وما الحد الأدنى المطلوب لفترة فحص RSS وحدود جلب HTML؟ هل يُسمح بعرض مقتطف RSS أو الوصف الكامل والمعلومات المستخرجة وتخزينها محليًا؟ وما شروط النسبة للمصدر والاحتفاظ والحذف؟ هل توصي المنصة بتكامل آخر مصرح به؟ سأراجع الحدود التي تحددونها قبل اعتماد التوزيع الموسع.

راصد يُعرض كمشروع مستقل، مع رابط المشروع الأصلي، ولا يدّعي شراكة مع حسوب. معلومات المطور: https://www.linkedin.com/in/david-atef/

شكرًا لتوضيح الإذن والحدود المطلوبة.
