# RASED 0.2.3 — تسليم الشروط والخصوصية وهوية النافذة

التاريخ: 2026-09-26. تنفيذ محلي بطلب المستخدم؛ لم يحدث commit أو push أو نشر Release. تفاصيل التحليل القانوني وحدوده في [LEGAL_REVIEW](legal/LEGAL_REVIEW.md).

## المنفذ

- صفحات offline بالعربية والإنجليزية داخل الإعدادات → الشروط والخصوصية: شروط الاستخدام، الخصوصية، الرخص والحقوق. رابط إضافي من «حول راصد» وروابط رسمية تفتح في المتصفح عبر allowlist.
- TERMS.md وPRIVACY.md ونص MIT و12 إشعار ترخيص كاملًا، تُجمع عبر prebuild وتُرفق داخل resources/legal في النسخة المجمعة. الحفاظ على ملفات رخص Electron/Chromium.
- شريط نافذة مخصص للرئيسية وcompact، بألوان الثيم وdrag region وأزرار minimize/maximize/restore/close؛ يرسل كل زر أمرًا محدودًا لنافذته، ويستمر حارس الملاحظات وسياسة الإغلاق. لم تُضعف contextIsolation أو sandbox أو CSP.
- علامة بوصلة SVG بنفس اللون الأساسي #7aa3d4، وخلفية شفافة وتوسيط الرسم؛ جميع PNG/ICO/Tray من المصدر نفسه. alpha bbox النهائي (54,70,459,442) على512×512، ومركزه(256.5,256)، أي نصف بكسل أفقيًا.
- الأيقونة في BrowserWindow وAppIconPath ومسار resources/branding/icon.ico الحقيقي خارج ASAR، مع AppUserModelID نفسه. مقارنةSHA256 بين الأصل والنسخة المرفقة مطابقة. التنفيذي والمثبت بُنيا باستخدام ICO نفسها؛ لم يُعدل Electron.exe.

- typecheck وlint وbuild وdist ناجحة. `npm test`: **88/88، 13 ملفًا**.
