# خطة إصلاح RASED 0.2.x

المرجع: UI_UX_INDEPENDENT_REVIEW.md. طلب المستخدم يشمل التنفيذ الفعلي لجميع نتائج المراجعة، وإصلاح زر الفتح في المتصفح. لا نشر تلقائيًا إلى GitHub.

## ترتيب التنفيذ

1. إصلاح IPC الفتح الخارجي وربط الصوت، وإظهار فشل الفتح بدل تجاهله. الاختبار يمر عبر preload/handler الحقيقي مع opener آمن عند الاختبارات، ثم تجربة المتصفح الفعلية.
2. توحيد التنقل وحارس المسودات قبل مغادرة الصفحة، بما فيها sidebar/compact/غلق النافذة. فصل حالة التفاصيل حسب ID، ورفض مغادرة الصفحة بعد فشل الحفظ.
3. توحيد تعريف فلتر العرض المحفوظ، مع الحفاظ على search/scope والتحديث الذري عند الربط. تفعيل المخفية والاسترجاع فعلًا.
4. تحميل الصفحات وتجميعها بعد 200، واستعادة نطاق القائمة وanchor/scroll بعد تركيب الصفوف؛ حفظ مصدر الرجوع.
5. معالجة الأحداث الجديدة والمعدلة دون قفز أو إبطال fetch بسبب حدث فارغ، وبنفس قواعد query. إصلاح اختصارات الصفوف والمعاينة.
6. توحيد ميزانية طلبات HTML، وإلغاء/تصفية الطلبات عند الحذف والخروج، وتحديث cache حسب TTL، وتمييز الوصف المقتطع، وإعادة استخدام metadata من تفاصيل المشروع.
7. بث الإعدادات والصحة لكل النوافذ، وإعادة فحص DND قبل الإرسال والصوت، وتصحيح مواضع compact وحراسة تنقل Electron.
8. تحسين focus/keyboard/empty/offline/الاختصارات؛ تأمين سكربتات الاختبار وتنظيف أمثلة استخدامها.
9. اختبارات انحدار حقيقية لكل مشكلة، وترحيل DB v2 فعلية، واختبار wiring/واجهة بقاعدة temporary وfixtures ثابتة، ثم build/dist جديد وصور وتقرير نتائج وحدود QA.

## قواعد التنفيذ

- الحفاظ على تعديلات التنفيذ الموجودة وبيانات المستخدم وإصلاحات RSS السابقة.
- الاختبارات على profile مستقل فقط؛ لا اختبار حذف أو تغيير إعدادات على قاعدة المستخدم.
- لا تغيير للستاك أو مشروع بديل، ولا تقليل النطاق بصمت.
- الإغلاق ينتظر العمليات التي قد تكتب DB؛ لا sleep كحل للتزامن.
- تحديث تقرير الإصلاح بنتائج التنفيذ والاختبارات الفعلية، مع فصل ما لم يُختبر يدويًا.

## القبول

- R01–R17 معالجة ومربوطة بكود/تحقق واضح.
- زر المتصفح يستدعي handler مسجل، ويفتح رابط DB المسموح؛ القراءة بعد نجاح الفتح فقط.
- ملاحظة dirty لا تضيع من تنقل/غلق؛ hidden/save/filter/عودة/paging/compact تعمل عبر bridge الحقيقي.
- لا false success في اختبارات الفلتر/التمرير/DND/الصوت، ولا claim وصف كامل لنص مقتطع.
- نجاح typecheck/lint/tests/build والتجارب المعزولة؛ مثبت جديد محلي مع SHA256 صحيح، دون رفع أو نشر.

## نتيجة التنفيذ

نُفذت المراحل، والإصدار المحلي0.2.1 بُني واختُبر. نتائج R01–R17 و88 اختبارًا و37 فحصًا على النسخة المجمعة والمثبت وبصمته وحدود QA موثقة في [UI_UX_FIX_REPORT.md](UI_UX_FIX_REPORT.md). لا نشر تلقائيًا.
