# RASED 0.4.0 — Nafezly monitoring and source-neutral interface

RASED now watches public [Nafezly project RSS](https://nafezly.com/feed) alongside Mostaql projects and Khamsat unavailable-service requests. Nafezly has its own status, pause and alert controls. Its first scan silently saves existing projects; later scans deduplicate by source and project ID and alert on newly published matches. Alerts can use optional include/exclude words in the title and full RSS description. The full RSS description is stored locally and displayed on the in-app project page without requesting Nafezly detail pages. Project buttons and Windows notifications open the original project in the default browser.

The Arabic/English interface now treats RASED as a watcher across platforms: source choices, health indicators, tray controls, filters and project cards include the third source. Display filters search Nafezly titles and stored excerpts; the separate Nafezly alert words search the full RSS description. Category and budget are not inferred from free text. The Gemini Proposal Assistant remains limited to Mostaql projects.

The normal Nafezly interval is about 15–18 seconds after each completed request, independent of project activity. Access errors and rate limits trigger backoff, with a gradual return to the normal interval. This is a local app: no Nafezly login, browser-session access or automated proposals. The RSS contains a limited number of items, so a project may be missed if it leaves the feed between checks. Publication-to-alert latency cannot be guaranteed.

## Verification and limits

Typecheck, ESLint, 115 unit tests and a production build passed. The packaged Windows application passed 82 Electron/preload/React/SQLite integration assertions, covering a silent Nafezly baseline, independent pause, a fresh project alert with browser URL, source filtering, full local description and the external-open action. A separate isolated QA NSIS test passed a real update/download/checksum/relaunch sequence and preserved SQLite data; it did not modify the normal RASED installation. The public RSS endpoint was reachable during research and its observed XML shape was checked, including a leading newline before the XML declaration. No genuinely new Nafezly project appeared during the live observation period, so live publication-to-notification time has not been measured. The 15–18 second interval succeeded in a limited probe on one device; it is not an official rate allowance.

Users on RASED 0.2.5 or newer can check, download and explicitly install this release from Settings → RASED updates. Others can install the Windows x64 setup from this release. Existing local settings and SQLite data use the same app ID and folder. The installer is unsigned; compare its SHA-256 with `SHA256SUMS.txt` when downloading manually.
